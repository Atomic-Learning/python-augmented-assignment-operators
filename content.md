The augmented assignment operators are a family of operators which perform an arithmetic operation on a variable and then assign the result back to that variable. They provide a compact way to update the value of a variable without having to repeat the variable name.

# Addition

```py-cell
x = 5
x += 3  # Equivalent to x = x + 3
print(x)
```

# Subtraction

```py-cell
x = 5
x -= 3  # Equivalent to x = x - 3
print(x)
```

# Multiplication

```py-cell
x = 5
x *= 3  # Equivalent to x = x * 3
print(x)
```

# Division

```py-cell
x = 5
x /= 3  # Equivalent to x = x / 3
print(x)
```

# Floor Division

```py-cell
x = 5
x //= 3  # Equivalent to x = x // 3
print(x)
```

# Modulus

```py-cell
x = 5
x %= 3  # Equivalent to x = x % 3
print(x)
```

# Exponentiation

```py-cell
x = 5
x **= 3  # Equivalent to x = x ** 3
print(x)
```
